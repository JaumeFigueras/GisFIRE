EGIF wildfire report
====================

The part of the *parte* that only the XML export publishes: control and response times,
how the fire was detected, how certain its cause is, the weather at the time, and the
severity index. A one-to-one optional child of :doc:`egif_wildfire`, whose presence is
how the schema records which export a fire was read from.
