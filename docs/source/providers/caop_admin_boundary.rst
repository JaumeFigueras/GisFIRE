CAOP administrative boundary
============================

The administrative boundary model for the *Carta Administrativa Oficial de Portugal*,
published yearly by the DGT at https://www.dgterritorio.gov.pt/dados-abertos.
See :doc:`caop_provider` for the dataset itself, :doc:`../providers` for how provider
models relate to the generic ones, and :doc:`../data_model/geography_admin_boundary` for
the columns it inherits.
