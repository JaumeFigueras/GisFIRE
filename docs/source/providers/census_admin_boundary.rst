US Census Bureau administrative boundary
========================================

The administrative boundary model for the states and counties of the Census Bureau's
Cartographic Boundary Files, published at
https://www.census.gov/geographies/mapping-files/time-series/geo/cartographic-boundary.html.
See :doc:`census_provider` for the files themselves, :doc:`../providers` for how provider
models relate to the generic ones, and :doc:`../data_model/geography_admin_boundary`
for the columns it inherits.
