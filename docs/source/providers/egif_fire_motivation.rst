EGIF fire motivation
====================

The ``idmotivacion`` catalogue: why an intentional fire was lit, 28 codes with their
published Spanish labels. Published on the fires whose cause is ``400`` and on no
others. See :doc:`egif_fire_cause` for the code space it must not be joined with.
