EGIF wildfire
=============

The *parte de incendio forestal* model for the Spanish national fire statistics. See
:doc:`../providers` for how provider models relate to the generic ones,
:doc:`../data_model/wildfire` for the columns it inherits, :doc:`egif_ignition` for the
point it is mapped at, :doc:`egif_fire_cause` and :doc:`egif_fire_motivation` for what
its two code foreign keys point at, and :doc:`egif_wildfire_report` for the detail only
the XML export publishes.
