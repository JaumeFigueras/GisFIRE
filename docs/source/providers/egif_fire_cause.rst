EGIF fire cause
===============

The ``idcausa`` catalogue, as a lookup table: 87 codes across the 2022 and 2023
campaigns, each with the Spanish label the Excel export prints beside it. See
:doc:`egif_fire_motivation` for the *other* code space, which overlaps this one and
means different things, and :doc:`egif_provider` for the cause families.
