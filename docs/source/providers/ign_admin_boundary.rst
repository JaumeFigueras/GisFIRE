IGN administrative boundary
===========================

The administrative boundary model for the *Base de Datos de Divisiones
Administrativas de España*, published by the Instituto Geográfico Nacional through
the CNIG download centre at https://centrodedescargas.cnig.es.
See :doc:`ign_provider` for the dataset itself, :doc:`../providers` for how provider
models relate to the generic ones, and :doc:`../data_model/geography_admin_boundary`
for the columns it inherits.
